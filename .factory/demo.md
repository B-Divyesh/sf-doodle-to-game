# Demo sandbox

Open `/demo` or `/?demo=1` for the one-click sample. It starts **Maya and
Theo’s doodle dodge** with two original built-in drawings and the playable game
already open.

The persistent banner says “Demo — sample data, nothing is saved.” **Reset
demo** restores the supplied drawings and rule. **Start for real** goes to the
empty personal workshop. Demo work uses the `doodle-to-game-demo` IndexedDB
database; real work uses `doodle-to-game`. The two stores never share a record.
